# AgentSkills

## 全域連結

這個 repo 的 skill、agent、instruction（`CLAUDE.md`、`copilot-instructions.md`）要怎麼曝露成
每台機器的全域路徑、連結要怎麼檢查與修復、Windows／macOS 各自該用哪種連結指令、以及
Junction／SymbolicLink／HardLink 的原理差異，都完整寫在
[`agentskills-conventions`](.agents/skills/agentskills-conventions/SKILL.md) 這個 skill 裡
了（連結原理另外放在它的 `references/link-types.md`），不重複寫在這份 README。

想建立或檢查連結，直接請 AI 讀那份 skill 就好。
