# PXBOX-26324 詳細實例化 TC — 折價券（迴歸保護）

> 高階 AC 詳見 [pxbox-26324_ac.md](pxbox-26324_ac.md) `AC-折價券-1` 章節。本檔為對應的詳細測試案例（含 Given/When/Then 與計算追蹤）。

> 範圍：折價券攤回邏輯（單一折價券攤提的邊界 case — 對應方法 `AssignCouponDiscount`）。
> 本次需求只動現折邏輯，不會動到折價券；本檔列出折價券當前的均攤行為作為迴歸保護用。
>
> **折價券只在試算階段處理**；成單階段（服務進入點）**不處理折價券**。
>
> **本檔不涵蓋**：
> - 折價券「可用性篩選」（由 `get_available_coupons` API 處理，前端取得可用清單）
> - 折價券「計算總折扣」（由 `GetCouponDiscountAmount` 處理，含門檻、折數、上限），非本檔範圍
> - 本檔只列「折扣金額算出後，攤回到各商品」的均攤邊界 case

> **術語對照表**：本檔使用的領域術語對應到系統欄位
>
> | 領域術語 | 系統欄位 |
> |---|---|
> | 折價券 ID | `coupon.CouponId` |
> | 折扣金額（總） | `coupon.DiscountAmount` |
> | 折價券適用商品 | `request.CouponProductIds` |
> | 折價券類型 | `coupon.CouponType` |
> | 商品折扣後金額 | `Item.Amount` |
> | 折價券折抵金額（per item） | `Product.CouponDiscountAmount` |
> | 折價券明細 | `Product.Coupon`（含 `CouponId` / `DiscountAmount`） |
> | 計算階段 cap | `GetCouponDiscountAmount` 內部處理 |
> | 攤回階段 | `AssignCouponDiscount` 內部處理 |

> **驗收欄位對照**：每個 TC 的 Then 段檢查 `result.Products` 中每商品的折價券折抵：
>
> **每商品折扣明細**（每商品下最多一筆折價券折抵）：
> - **折價券折抵總額**（`Products[].CouponDiscountAmount`）：此折價券折給該商品的金額
> - **折價券明細**（`refItem.Coupon`，內含 `CouponId` 與 `DiscountAmount`）：哪張折價券、折多少
>
> 折價券一次只能用一張，所以每商品的 `Coupon` 是單一物件（非 list），與現折的 `Discounts` list 不同。

> **計算階段 cap**：`GetCouponDiscountAmount` 在算出總折扣後，若 `totalDiscount > totalAmount`，會先 cap 至商品總額（`totalDiscount = (int)totalAmount`）；之後再進入 `AssignCouponDiscount` 攤回，攤回時仍每件保留 $1。TC-折價券攤回-02 與 -06 觸發此 cap。

## 折價券攤回（共用邏輯）

> `AssignCouponDiscount` 攤回邏輯與 `AssignPromotionDiscount` 幾乎相同（兩輪攤提、保留 $1 等），差別只在折抵記錄到不同欄位（`CouponDiscountAmount` / `Coupon` 物件）。本章列出單一折價券攤回的邊界 case。

**TC-折價券攤回-01 基本攤回（按金額大到小依比例）**
- Given：2件（A $1000，B $500，總 $1500），折價券 C 折扣金額: $100
- When：呼叫折扣計算
- Then：
  - **各商品折價券折抵明細**：
    - A 折 $67（`Round($1000/$1500 × $100) = Round($66.67) = $67`，→ $933），明細記錄折價券 C 編號、折扣金額 $67
    - B 折 $33（`Round($500/$1500 × $100) = Round($33.33) = $33`，→ $467），明細記錄折價券 C 編號、折扣金額 $33

**TC-折價券攤回-02 折扣超過商品總額時，每件最低保留 $1**
- Given：2件（A $30，B $20，總 $50），折價券 C 設定折扣金額: $100
- When：呼叫折扣計算
- Then：
  - `GetCouponDiscountAmount` 先 cap：$100 > $50（總額）→ 折扣降為 $50 進入攤回
  - 攤回時每件保留 $1：
    - A 折 $29（→ $1），明細記錄折價券 C 編號、折扣金額 $29
    - B 折 $19（→ $1），明細記錄折價券 C 編號、折扣金額 $19
  - 實際生效折扣 = $48，超額 $2 靜默丟棄

**TC-折價券攤回-03 第一輪均攤金額捨入為零時，強制補 $1**
- Given：3件（A $1000，B $1000，C $2，總 $2002），折價券 C 折扣金額: $301
- When：呼叫折扣計算
- Then：
  - A: `Round($1000/$2002 × $301) = Round($150.35) = $150`（→ $850）
  - B: `Round($1000/$2002 × $301) = $150`（→ $850）
  - C: `Round($2/$2002 × $301) = Round($0.30) = $0`，因仍有剩餘折扣，強制補 $1 → C 折 $1（→ $1）
  - 各商品折價券明細各記錄折扣金額 $150 / $150 / $1

**TC-折價券攤回-04 第一輪折扣分完，未輪詢到的商品不分得折扣**
- Given：3件（A $1000，B $1000，C $2），折價券 C 折扣金額: $300
- When：呼叫折扣計算
- Then：
  - 第一輪由金額大到小依序處理，A 折 $150（→ $850）、B 折 $150（→ $850），剩餘折扣歸 0，第一輪提前結束
  - C 未被輪詢到，不分得折扣（→ $2，無折價券明細）
  - 第二輪因剩餘折扣為 0 不觸發
  - A、B 明細各記錄折扣金額 $150

**TC-折價券攤回-05 第一輪結束有剩餘折扣，第二輪補給金額最高商品**
- Given：3件（A、B、C 各 $100，依此順序排列），折價券 C 折扣金額: $10
- When：呼叫折扣計算
- Then：
  - 第一輪各件按比例均攤約 $3.33，四捨五入後各 $3 合計 $9，剩餘 $1 進入第二輪
  - 第二輪補給金額最高商品，多件並列最高時補給排序第一件 A
  - 最終：A 折 $4（→ $96），B、C 各折 $3（→ 各 $97）
  - 各商品折價券明細各記錄折扣金額 $4 / $3 / $3

**TC-折價券攤回-06 第二輪所有商品已剩 $1，剩餘折扣靜默丟棄**
- Given：2件（A $5，B $3，總 $8），折價券 C 設定折扣金額: $20
- When：呼叫折扣計算
- Then：
  - `GetCouponDiscountAmount` 先 cap：$20 > $8（總額）→ 折扣降為 $8 進入攤回
  - 第一輪 A 折 $4（→ $1）、B 折 $2（→ $1），實際生效 $6
  - 第二輪因兩件商品都已剩 $1，無可再分配對象，剩餘折扣 $2 靜默丟棄
  - 各商品折價券明細各記錄折扣金額 $4 / $2
